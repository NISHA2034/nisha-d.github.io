Projects

★ FEATURED PROJECT
🔋 Wireless Battery Management System (BMS)
Research on wireless analog front-end (AFE) implementation using hybrid monitoring combined with CNN and LSTM deep learning techniques for signal noise reduction. Incorporates acoustic testing for cell health diagnostics. Also developed wireless IoT monitoring of real-time battery parameters — voltage, current, temperature — via ThingsBoard dashboard. Features adaptive heartbeat transmission that scales from 1 Hz (stable) to 5 Hz (anomaly detected) to minimise wireless overhead.
STM32 ESP32 CNN / LSTM AFE Design ThingsBoard Python Acoustic Testing
PROJECT 02
🗑 Smart Bin — IoT Waste Monitor
Designed and built a Smart Bin using Arduino, an ultrasonic distance sensor, and GSM module. The system monitors fill level in real time and sends alerts to prevent overflow, enabling smarter urban waste management.
Arduino Ultrasonic Sensor GSM Module IoT

⚡ Footstep Power Generation System
Built an energy harvesting system using piezoelectric sensors that converts mechanical energy from human footsteps into usable electricity. Arduino processes the output and displays the generated voltage live on an LCD screen.
